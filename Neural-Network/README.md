## Neural Network
# Student Result Prediction Using Neural Network

## About

A simple Neural Network project that predicts whether a student will PASS or FAIL based on academic performance and attendance.

## Features

* PASS/FAIL prediction
* Prediction probability
* Model accuracy
* Automatic student dataset generation
* Training loss graph
* New student prediction

## Input Features

* Study Hours
* Attendance
* Previous Marks
* Assignment Score

## Technologies Used

* Python
* NumPy – Neural Network calculations
* Pandas – Dataset handling
* Matplotlib – Graph visualization
* Git & GitHub – Version control

## Output

The model provides:

* Predicted Result: PASS / FAIL
* Prediction Probability
* Test Accuracy

## How to Run

Install the required libraries:

```bash
pip install numpy pandas matplotlib
```

Run the program:

```bash
python "Task 2.py"
```
