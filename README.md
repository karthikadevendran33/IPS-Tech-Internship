# IPS-Tech-Internship
Thirukkural Finder

Thirukkural Finder is a simple web application that makes it easy to search and explore the 1,330 couplets of the Thirukkural. Users can enter a Kural number and instantly view the original Kural along with its meaning. The application also supports both Tamil and English for a more accessible experience

## Features
Kural Search – Search any Thirukkural from 1 to 1330.
Kural & Meaning – View the selected Kural along with its meaning.
Tamil & English Support – Switch between Tamil and English.
API Integration – Fetches Kural data dynamically from a public API.
Input Validation – Handles invalid Kural numbers with clear error messages.
Responsive Design – Works smoothly across desktop and mobile devices
