# Rock-Paper-Scissor
# About the game

A simple and interactive two-player Rock Paper Scissors web game built using Python and Flask.The game allows two players to play against each other through a web interface. Each player chooses Rock, Paper, or Scissors, and the application determines the winner based on the standard Rock Paper Scissors rules.
